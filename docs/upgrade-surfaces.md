# Upgrade surfaces

A pool of axes to upgrade, not a design. Nothing here is decided, priced or
placed on a shelf; `design.md` §10 and §18 own where things go once they are.

Constraint on every row: **the wave is a clock** — nothing buys wave speed (§7).

## From the author

- **Re-aim penalty cost**
- **Re-aim penalty length**
- **Learning token** — a small random share of a cohort's yield converted to
  knowledge. A second knowledge source beside the split; makes it partly luck.
- **Click power as a share of income** — the shape §19 *The click* already asks
  for. Regular upgrades will target it often.
- **Synergies** — cohort X boosts Y, likely each boosting the next; one per
  upgrade.
- **Planet yield strength** — a rate multiplier, so it overlaps wisdom's +2%.
  Stays out of wisdom's lane only if per-world and Crimson-priced.
- **Harness synchronisation** — worlds yield at the same time; makes harvest
  timing a choice.

## Wave and aim

- **Phase forecast** — next phase's length and strength. Foresight.
